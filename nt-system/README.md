# NT-System

Samlet system for Nortrapp, fra forespørsel til ettermarked. NT-Arkivet blir prosessmotoren i systemet.

## Mockup

`mockup/` er en klikkbar skisse med oppdiktede eksempeldata. Den lagrer ingenting.

- Åpne `mockup/index.html` i nettleseren, eller
- lag én fil med `python3 mockup/bygg.py NT-System-mockup.html`.

Moduler i skissen: dashbord per rolle, NT-Kalk (henvendelser, kalkulasjon, prisliste), prosjekter med parallelle
delspor og 3D/deleliste, dekktrinn-bestilling, fabrikklayout, stasjonsskjerm med Stream Deck, kapasitet og
normtider, bemanning og kompetanse, varer (råvare/skaffevare/lagervare), pakking og transport, økonomi/Tripletex,
ettermarked, innstillinger, lagring og backup.
